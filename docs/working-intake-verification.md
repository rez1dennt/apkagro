# Рабочий локальный приём, русская выгрузка и уточнение оформления

Обновление от 9 октября 2026 года по прямому запросу владельца.

## Текущее состояние

Приём включён в существующей локальной конфигурации на `127.0.0.1:3000`. Сервер перезапущен. Существующие ключ, администратор, пароль и обязательный TOTP сохранены. `APP_LEGALS_READY` не менялся; публичная инфраструктура и утверждение документов не заявляются готовыми.

Через обычную форму отправлена одна явно синтетическая заявка **«Тестовая Проверка Сайта»**, программа «Декоративное цветоводство». Сервер вернул HTTP 201, запись сохранена в текущем хранилище, два тестовых PDF зашифрованы. Заявка намеренно оставлена в кабинете для проверки владельцем. Номер: `123441b1-5424-4286-9ec9-578aaae331e8`. В тестовых документах нет персональных данных реальных людей.

## Изменения

- Возвращён скошенный верх callout в hero; криволинейные углы заданы SVG-подложкой. Текст и фотография находятся в разных flex-колонках с зазором 18 px.
- Заметка справа получила левый отступ 32 px. Форма резервирует место для неё на широком экране; при недостатке места декоративная заметка скрывается. Текст не перекрыт формой.
- Усилена светлая подложка карточки «Есть другие вопросы?», текст стал контрастнее.
- В Excel переведены все заголовки, названия программ, статусы и образование. Даты имеют русский формат с явным временем МСК. Телефоны/СНИЛС/почта остаются текстовыми ячейками без исполняемых формул. Добавлены фильтр, закреплённая строка и оформление.
- Кабинет обновляет список каждые 15 секунд. Скрытая вкладка и открытая карточка заявки приостанавливают фоновую загрузку. Обновление сохраняет фокус и текущие фильтры.
- Фоновые запросы не продлевают тайм-аут бездействия администратора. После выхода незавершённые запросы отменяются; проверка поколения авторизации исключает восстановление заявок устаревшим ответом и сброс новой сессии старым 401.
