# Рабочий локальный приём и уточнение дизайна

Прямой запрос владельца разрешает включить приём на текущем локальном сервере. Сервер остаётся на loopback; ключи, пароль и MFA сохраняются. Готовность юридических документов для публичного запуска не утверждается.
