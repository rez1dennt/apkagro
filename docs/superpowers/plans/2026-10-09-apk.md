# APK Education Implementation Plan

> For agentic workers: use subagent-driven-development for the independent server task, then integrate and review in the current session. Track progress below.

**Goal:** Build the supplied agrarian education reference as a responsive working site with a secured JavaScript server and administrator.

**Architecture:** Plain semantic HTML, shared CSS tokens and browser modules in public/. Node.js same-origin API and encrypted private storage outside public/. Separate legal routes and authenticated admin UI.

**Tech Stack:** HTML, CSS, JavaScript, Node.js 22+, image generation, ImageMagick WebP, Node test runner, browser QA.

## Global Constraints

- Match the user supplied layout and palette. No frontend framework.
- Six courses, 72 hours each; no invented learning guarantees or contacts.
- Never expose passport or personal SNILS of the operator.
- Mandatory MFA; no default admin password or browser-side authentication.
- Private applications and attachments encrypted outside public/.
- Real intake disabled until configured; never simulate a successful submission.
- 320px minimum viewport; no horizontal overflow, scroll jumps, or abrupt overlay motion.
- No public admin link; links for cloud documents remain explicit placeholders.
