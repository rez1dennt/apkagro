- [x] Реализовать общий select-only combobox для двух статусов с родным select как источником значения и fallback без JS.
- [x] Плавно открывать/закрывать listbox, вращать стрелку, поддержать выбранный/активный пункт, клавиатуру, Escape/Tab/outside click и reduced motion. Меню не должно обрезаться контейнером или модальным окном.
