# Обновление оформления и доступа

Пользователь явно запросил Esqadero FF CY 4F, детальные иконки, исправление удаления цифр после скобок маски и пароль администратора. Это уточнение существующего согласованного дизайна.

Визуальное направление: сохранить фотографии, секции и зелёно-золотую палитру; подключить локальный WOFF2 для заголовков и текста, заменить пиктограммы на детальные двухцветные SVG, добавить тонкие золотые рамки, лёгкую фактуру и глубину карточек. Сохраняем доступные подписи, клавиатуру, reduced motion, стабильный скролл и адаптив 320 px.

- [x] Воспроизвести ошибку маски в браузере, сохранить регрессии Backspace/Delete/выделения/вставки, исправить общий механизм масок с сохранением курсора.
- [x] Конвертировать найденный TTF в WOFF2, сохранить лицензионный текст/источник, подключить self-hosted font и проверить фактическую загрузку кириллицы.
- [x] Улучшить SVG-спрайт, карточки, шапку, первый экран, форму, детали разделов и диалоги без изменения серверных путей и обработки заявок.
- [x] По явному запросу пользователя создать локальную учётную запись с случайным длинным паролем и обязательным TOTP. Никаких секретов в public/. QR хранить отдельно, приватно и вне Git. Приём реальных заявок оставить выключенным. Не заменять уже существующие ключи/учётные записи.
- [x] Повторить mask regression, полный browser QA, актуальные unit/static/security проверки; открыть итоговый сайт и приватный QR для владельца, предоставить логин/пароль.

Доступ к кабинету не должен ослаблять MFA. Подключение шрифта к production требует подтверждения условий веб-использования: поставляемая лицензия ссылается на старую недоступную страницу стандартного соглашения; исходный каталог указывает бесплатное коммерческое использование. Документируем этот вопрос перед публикацией, не выдаём каталог за юридическое заключение.
