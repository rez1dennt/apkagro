# «Кадры в АПК»: согласованный проект

Пользователь 09.10.2026 одобрил полный сайт с сервером на JavaScript и защищённым кабинетом. Дизайн задан приложенным референсом и прямым требованием повторить его.

## Цель и интерфейс

Запись на онлайн-повышение квалификации. Светлая шапка, фотоблок с женщиной-агрономом справа, зелёно-золотая палитра, заголовки с засечками, белые мягкие карточки, волнообразные переходы. Секции: герой, преимущества, шесть программ, четыре шага, форма, FAQ, баннер, подвал. `/admin` отсутствует в публичной навигации. Мобильная навигация и модальные окна сохраняют положение прокрутки и ширину страницы. Проверяем 1440, 1024, 768, 360, 320 px. Учитываем reduced motion.

## Программы и заявка

Шесть программ по 72 часа: БАС в растениеводстве; декоративное цветоводство; виноделие и виноградарство; функциональное хлебопечение; сидродельческий проект; функциональные пищевые продукты и подбор рационов. Клик открывает доступный диалог с предварительной аннотацией и кнопкой выбора. Выбор переносится в форму. Аннотации не выдаём за утверждённый учебный план.

Фамилия, имя, отчество, дата рождения, телефон, email, СНИЛС, уровень образования (СПО/ВО либо студент 4-го курса и старше), копия СНИЛС, документ об образовании/справка. Отдельное согласие, не отмеченное заранее, со ссылкой на самостоятельную страницу. Из источника: срок приёма до 31.10.2026; указанное ограничение — профессиональное образование и промежуточная аттестация не менее трёх лет назад. Студенческий вариант в источнике конфликтует с этим ограничением; публикуем обе возможности из формы и явно просим уточнить условия перед запуском.

## Сервер и хранение

Node.js 22+, HTTP API одного origin, публичные файлы только из `public`. Вложения и база вне `public`. Шифрование AES-256-GCM, ключ из окружения. Пароль scrypt, обязательный TOTP, rate limit, непрозрачные сессии с HttpOnly/SameSite/production Secure cookie, CSRF, Origin check, ограничение сессии, журнал без ФИО/СНИЛС. Вход без стандартного пароля. Установка администратора локальным скриптом. Продакшн требует HTTPS, размещения базы и файлов в РФ, антивирусной проверки загрузок и резервного копирования. Без настройки и подтверждения организационных сведений реальный приём по умолчанию выключен.
