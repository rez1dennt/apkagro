# Плавные dropdown, поиск и окончание hero

Обновление от 9 октября 2026 года по скриншотам владельца.

## Что изменено

- Два списка статусов в кабинете используют общий select-only combobox. Исходные select сохраняют значения, события change и fallback при отсутствии JavaScript. Фильтрация и сохранение статуса используют прежний API.
- Listbox плавно появляется/закрывается; стрелка вращается. Поддержаны выбранный пункт, активный пункт, ArrowUp/Down, Home/End, Enter/Space, русский поиск по начальным буквам, Escape, Tab и закрытие снаружи.
- При недостатке места меню открывается вверх. Прокручивается только список опций; страница и модальное окно остаются на месте. Reduced motion завершает переход сразу.
- Поиск имеет один внешний контур фокуса. Внутренняя тень снята; геометрия поля сохраняется. Фокусная граница #85713f имеет расчётный контраст 4,74:1 на белом и 4,56:1 на открытой поверхности #fafbf6. Это отдельная измеренная пара цветов, не заявление о полном соответствии интерфейса WCAG.
- Скошенный блок hero сохранён, но отстоит на 24 px справа и 28 px снизу. Скруглённая подложка и мягкая тень обозначают его окончание; текст и фото не пересекаются.

## Причины и регрессии

До исправления оба dropdown были native select со статичной стрелкой. Фокус создавал одновременно две тени — input и label. На 768 px раскрытое содержимое контейнера таблицы распространяло её scrollable overflow на документ; paint containment задан собственному scroll-контейнеру таблицы, а не всему сайту.

Независимое ревью выявило отсутствие прокрутки активной опции и слабый новый контур фокуса. Короткий viewport 320×260 воспроизвёл невидимый активный пункт; после локальной прокрутки панели тест прошёл. Цвет фокуса усилен и сохраняется при открытии.
