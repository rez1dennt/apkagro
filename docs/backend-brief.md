Use TDD on security behavior and run checks.

Implement a realistically secured same-origin Node server serving public/ at 127.0.0.1:3000 by default. Prefer minimal maintained dependencies (busboy for streaming multipart and exceljs for real xlsx are acceptable); npm install local is authorized. Private files under data/, not served. No browser auth or default credentials. Do not log PII or passwords. Use scrypt (OWASP parameters if practical), mandatory TOTP RFC6238 with replay prevention, long unique password >=16, encrypted credential TOTP secret under AES-256-GCM app key. Local CLI setup via prompts, generate TOTP enrollment secret locally and do not expose it in your tool report. Could support controlled environment variables for automated tests but do not create production/demo credentials. Server must run for preview without admin configured. Intake defaults disabled until APP_INTAKE_ENABLED=true and admin/config exist; GET /api/config exposes enabled boolean and version only. Do not silently create encryption key for production. .env.example placeholders, Node --env-file-if-exists supported. Production refuse insecure transport/origin/missing encryption and scanner/legals readiness.
